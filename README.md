# 🚀 GrowMore - Full Stack Application

A complete referral-based growth platform built with React, Node.js, Express, and MongoDB.

## Features
- User Registration with validation
- Secure JWT Authentication
- Unique Referral Code System (GM prefix)
- Captcha Verification
- Welcome Modal with countdown
- Responsive Mobile-First Design
- Protected Routes
- Dashboard with Referral Stats

## Tech Stack
- **Frontend:** React 18, React Router 6, Axios
- **Backend:** Node.js, Express 4, JWT, Bcrypt
- **Database:** MongoDB with Mongoose ODM
